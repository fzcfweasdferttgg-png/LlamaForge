```bash
curl -fsSL https://raw.githubusercontent.com/dadwritestech/LlamaForge/master/install.sh | sh   # Linux / macOS
```
Они устанавливают оригинальный проект; эта сборка разворачивается из этого репозитория. Затем **Install llama.cpp** (официальная сборка для вашей видеокарты, без компилятора) → **Discover** → **Load**.
Ранняя предварительная версия: Windows + NVIDIA — наиболее протестированный путь. Linux и macOS проходят CI, но почти не использовались на реальном оборудовании.

LlamaForge не запускает модели сам. Он устанавливает и управляет собственным роутером llama.cpp — `llama-server` —
и редактирует его `models.ini` за вас. Не аффилирован с ggml-org. Если вам важнее лоск,
а не контроль, используйте [LM Studio](https://lmstudio.ai), [Ollama](https://ollama.com) или [Jan](https://jan.ai).

## Зачем LlamaForge

Новые архитектуры моделей появляются в llama.cpp первыми. Настольные приложения подхватывают их при следующем
обновлении встроенного движка. LlamaForge запускает **сам официальный релиз llama.cpp** (или
вашу собственную сборку либо форк), поэтому новая модель — это один клик **Update**, а UI покрывает
каждый флаг сервера, а не отобранный набор.

| | **LlamaForge** | LM Studio | Ollama |
|---|---|---|---|
| Открытый исходный код | ✅ MIT | ❌ проприетарное приложение | ✅ MIT |
| Движок | официальные апстрим-сборки llama.cpp, любая версия, или свой форк | встроенные рантаймы llama.cpp / MLX от LM Studio | собственный движок Ollama на ggml |
| Настройки отдельных моделей | каждый флаг из `llama-server --help` (200+ в текущих сборках) | много, отобранные | параметры Modelfile |
| Любой GGUF с Hugging Face, с оценкой под вашу VRAM до загрузки | ✅ (грубая оценка) | ✅ | скачивает GGUF, без оценки вместимости |
| OpenAI + Anthropic-совместимый API | ✅, плюс настройка Claude Code / Codex / pi.dev в один клик | ✅ | ✅ |
| Зависимости бэкенда | нет (Python stdlib) | – | – |
| Нативное настольное приложение | ❌ работает в браузере | ✅ | ✅ |
| Зрелость | **ранняя предварительная версия** | зрелые | зрелые |

## Что внутри

- **Models**: все модели на вашей машине в одном списке, с текущими VRAM/загрузкой/температурой по каждой видеокарте. Загрузка, выгрузка или настройка прямо из строки.
  - Развёрнутая модель показывает редактор всех флагов llama-server, сгруппированных и с поиском, рядом с карточкой метаданных GGUF (архитектура, квант, обученный контекст, слои).
  - Сохранение перезагружает модель на месте. При сбое загрузки показывается последняя ошибка из журнала роутера с предположительной подсказкой.
  - Пресеты, профили запуска (модель + пресет + закреплённая сборка llama.cpp в один клик), сравнение бок о бок и сниппеты для клиентов, готовые к копированию.
  - Включите **Multi-model** в Setup, чтобы держать загруженными основную модель и воркеров одновременно. Планировщик размещает каждую на подходящих видеокартах по следам памяти, измеренным на вашей машине. Модель можно закрепить за собственной сборкой llama.cpp (или ik_llama.cpp).
- **Voice**: синтез речи на вашей видеокарте через собственный `llama-tts` из llama.cpp: Qwen3-TTS на 10 языках или крошечный английский Pocket TTS, работающий быстрее реального времени даже на CPU, опционально голосом, который вы запишёте или загрузите (клонируйте только голоса, которыми вам разрешено пользоваться).
- **Embers**: небольшие локальные агенты, следящие за темой, ведущие собственную вики и пишущие вам бриф по расписанию. Запись вики засчитывается только если цитирует источник дословно. **Forge** создаёт агента, опрашивая вас; **Model Scout** не требует настройки. У Embers нет браузера и инструментов, и ничего не покидает машину, пока не включены push-уведомления.
- **Discover**: поиск GGUF по Hugging Face, открывающийся с новинками недели. Каждый квант получает грубую оценку вместимости под вашу VRAM до загрузки (FITS / TIGHT / CPU OFFLOAD). Загрузки возобновляются после обрыва, регистрируются сами и завершаются готовностью к **Load**.
- **Will it run?**: выберите репозиторий и квант — получите вместимость и грубую оценку скорости.
- **Build / Update**: официальные сборки llama.cpp в один клик с откатом или сборка из исходников с флагами, определёнными для вашей видеокарты. Также управляет [ik_llama.cpp](https://github.com/ikawrakow/ik_llama.cpp) и, в Windows, [vLLM](https://github.com/vllm-project/vllm) в WSL2.
- **Stats**: токены, скорость и число запусков по моделям — из собственных метрик роутера. Статистика по клиентам невозможна: клиенты обращаются к роутеру напрямую.
- **Context**: markdown-документы контекста, собираемые в профили, внедряемые в запросы или записываемые в `CLAUDE.md` / `AGENTS.md`.
- **Recipes**: публикация профиля в виде читаемого JSON; другие импортируют его одним вставанием, и LlamaForge скачает модель, если её нет. Есть [галерея сообщества](../../recipes/).

Мастер первого запуска и переключатель **Lite / Advanced** держат продвинутые настройки подальше, пока они не нужны. Тема по умолчанию, **Stowage**, рисует каждую видеокарту как схему отсеков с сеткой в 1 ГиБ; **Hearth** и **Classic** — в один клик, и каждая доступна в светлой, тёмной и безопасной для дальтоников версии.

## Использование из других приложений

Всё, что говорит на OpenAI API (Open WebUI, SillyTavern, Continue, Cline, Aider, OpenAI SDK), работает с
`http://127.0.0.1:8080/v1`. Роутер всегда запущен с API-ключом, а **Client Config** у любой модели даёт вам
base URL, ключ и model id, готовые к вставке.

- **Anthropic-совместимый** `POST /v1/messages` на панели, со стримингом и вызовом инструментов.
- **OpenAI speech-совместимый** `POST /v1/audio/speech` на панели (WAV или PCM) на базе `llama-tts`.
- **Connect an agent** записывает конфигурацию для **Claude Code**, **Codex** и **pi.dev** (каждый затрагиваемый файл сначала резервируется).
- Эндпоинты загрузки/выгрузки позволяют агенту подменять модели по запросу.
- **MCP server** (stdio, `backend/mcp_server.py`; эта сборка также поставляет опциональный транспорт
  Streamable HTTP, см. документацию): Claude Code, Codex или любой MCP-клиент видят, что загружено,
  загружают и выгружают модели, проверяют вместимость, скачивают GGUF с Hugging Face и передают целую задачу
  [pi](https://github.com/earendil-works/pi), работающему на загруженной локальной модели (`pi_run`). Настройка одной строкой — в
  **Setup -> MCP server**, например `claude mcp add --scope user llamaforge -- python <LlamaForge>/backend/mcp_server.py`.

## Установка

Приведённые выше однострочники устанавливают оригинальный проект; эта сборка разворачивается из этого репозитория. См. [Отличия форка](fork-diff.ru.md).

Установщик находит Python 3.10+ (в Windows при его отсутствии устанавливает приватную копию embeddable Python
с python.org, закреплённую по SHA-256), скачивает свежий релиз, добавляет запись в
меню «Пуск» / меню приложений (`~/Applications/LlamaForge.app` на macOS, плюс команда `llamaforge`
в Linux/macOS) и открывает дашборд. Обновление сохраняет ваши настройки, модели и
движки. Удаление — через **Apps & Features** в Windows или `llamaforge uninstall`; перед изменением
настроек или моделей запрашивается подтверждение.

<details><summary>Из исходников (git clone)</summary>

```powershell
git clone https://github.com/dadwritestech/LlamaForge
cd LlamaForge
powershell -ExecutionPolicy Bypass -File bootstrap.ps1   # Windows
./bootstrap.sh                                           # Linux / macOS
```

Скрипт bootstrap проверяет наличие Python и Git (спрашивая перед установкой чего-либо),
записывает `config.json` и открывает дашборд.
</details>

**Ежедневное использование:** откройте **LlamaForge** из меню «Пуск» / меню приложений или выполните `llamaforge`.
Он запускает роутер и дашборд и открывает ваш браузер.

- Дашборд: http://127.0.0.1:8090
- API для других приложений: http://127.0.0.1:8080/v1

`llamaforge stop` (или `stop.ps1` / `stop.sh`) останавливает дашборд, роутер и
порождённые им модели. Останавливаются только процессы, запущенные LlamaForge; любой другой
ваш llama-server не затрагивается.

**Требования:** Windows 10/11, Linux или macOS на Apple Silicon. Python 3.10+ (только stdlib;
установщик Windows приносит свой). Видеокарты NVIDIA (CUDA), AMD/Intel (Vulkan) или Apple (Metal)
используются при наличии; работает и без GPU. Для сборки из исходников также нужны Git, CMake, Ninja и
C++-компилятор — вкладка Setup может установить их там, где позволяет пакетный менеджер.

## Как это работает

LlamaForge не содержит кода llama.cpp. Python-бэкенд на чистом stdlib управляет собственным
router API llama.cpp, редактирует `models.ini` и скачивает официальные сборки (или вызывает `git` / `cmake`).
Список настроек разбирается на лету из `llama-server --help`, поэтому соответствует запущенной вами сборке.

LlamaForge не фиксирует размер контекста, число GPU-слоёв и разбиение по видеокартам. `--fit` из llama.cpp
(включён по умолчанию) подбирает все три под свободную VRAM при загрузке и при необходимости переносит
эксперты MoE на CPU. Фиксация любого из них отключает fit, поэтому они остаются незаданными, пока вы не зададите их сами.

**Безопасность:** дашборд слушает только `127.0.0.1`, пока `panel_host` (эта сборка) не вынесет его
в локальную сеть. Роутер защищён ключом даже локально, поэтому открытая вами веб-страница не сможет им управлять; доступ из LAN
включается в Setup и требует ключ (в этой сборке `router_allow_keyless_lan` позволяет от этого
отказаться). Проверка Host/Origin остаётся включённой во всех режимах. Подробности и порядок приватного
сообщения об уязвимости: [SECURITY.md](https://github.com/dadwritestech/LlamaForge/blob/master/SECURITY.md).
