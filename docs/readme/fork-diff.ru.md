# Отличия форка

Оригинальный LlamaForge плюс перечисленные ниже изменения. Всё остальное — апстрим
без изменений. Тестировалось только на Ubuntu Server.

## Доступ из LAN (опционально)

`panel_host`, `chat_host` и `router_allow_keyless_lan` в `config.json` выносят
дашборд, прокси чата и роутер в локальную сеть. Значения по умолчанию
не меняются: привязка к loopback, и роутер по-прежнему отказывает без ключа.
Проверка Host/Origin остаётся включённой и дополнительно принимает собственные
имена машины. Подробности: [Конфигурация](../content/config.md),
[Безопасность](https://github.com/dadwritestech/LlamaForge/blob/master/SECURITY.md).

## MCP поверх HTTP (опционально)

`mcp_host` / `mcp_port` (по умолчанию `8092`) обслуживают MCP-сервер по безсостоятельному
Streamable HTTP рядом с stdio. По умолчанию выключено. Подробности: [MCP-сервер](../content/mcp.md).

## Телеметрия GPU без инструментов вендоров

Когда `nvidia-smi` отсутствует, состояние GPU (занято/всего VRAM, загрузка,
температура) читается из DRM sysfs ядра. Имена устройств и токены берутся
из `llama-server --list-devices`, поэтому планировщик мультимодельного режима говорит на `Vulkan0`,
а не только на `CUDA0`.

## Установка и обновления

Однострочные установщики из README устанавливают оригинальный проект. Эта сборка
разворачивается из этого репозитория. Встроенный обновлятор отклоняет копии без
манифеста установки (`.lf-files.json`); такие копии обновляются вручную.
