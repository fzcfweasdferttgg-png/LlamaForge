# Отличия форка

Оригинальный LlamaForge плюс перечисленные ниже изменения, без функций из раздела
*Удалено в этой сборке*. Тестировалось только на Ubuntu Server.

## Доступ из LAN (опционально)

`panel_host` и `router_allow_keyless_lan` в `config.json` выносят
дашборд и роутер в локальную сеть. Значения по умолчанию
не меняются: привязка к loopback, и роутер по-прежнему отказывает без ключа.
Проверка Host/Origin остаётся включённой и дополнительно принимает собственные
имена машины. Подробности: [Конфигурация](../content/config.md),
[Безопасность](https://github.com/dadwritestech/LlamaForge/blob/master/SECURITY.md).

## MCP поверх HTTP (опционально)

`mcp_host` / `mcp_port` (по умолчанию `8092`) обслуживают MCP-сервер по безсостоятельному
Streamable HTTP рядом с stdio. По умолчанию выключено. Подробности: [MCP-сервер](../content/mcp.md).

## Телеметрия GPU без инструментов вендоров

Когда `nvidia-smi` отсутствует, состояние GPU (занято/всего VRAM, загрузка,
температура) читается из DRM sysfs ядра. Имена устройств и токены берутся
из `llama-server --list-devices`, поэтому планировщик мультимодельного режима говорит на `Vulkan0`,
а не только на `CUDA0`.

## Модельный шлюз (LiteLLM)

Вкладка **Gateway** запускает [LiteLLM](https://github.com/BerriAI/litellm) (MIT)
как управляемый сайдкар: одно виртуальное имя модели распределяет запросы между
несколькими реальными моделями (`gateway_models`), настройка — свободными
пресетами LiteLLM (`gateway_presets`). По умолчанию выключено; свой порт
(`gateway_port`, по умолчанию 8300), своё venv (`tools/litellm/venv`),
управление через API панели и MCP-инструменты. Подробности: [Модельный шлюз](../content/gateway.md).

## Engines (готовые сборки)

Вкладка Build / Update теперь **Engines**: скачивание и выбор сборок трёх движков семейства
llama.cpp — llama.cpp (ggml-org), ik_llama.cpp (сборки Thireus) и beellama.cpp (Anbeeld) — и переключение того, что запускает роутер.
Сборка из исходников и бэкенд vLLM удалены. Подробности: [Engines](../content/build.md).

## Локализация интерфейса

Веб-интерфейс говорит по-английски, по-русски, по-японски, по-корейски и
по-китайски. Язык выбирается в топбаре рядом с бейджем движка и запоминается
в браузере (localStorage `lf_lang`); `web_lang` в `config.json` задаёт язык
панели по умолчанию. Непереведённые строки показываются по-английски.

## Удалено в этой сборке

Chat, Voice и Embers (мини-агент), вики Context, просмотрщик Help, часы в
топбаре и баннер кредитов/звёзд вырезаны. Всё остальное — апстрим без изменений.

## Установка и обновления

Однострочные установщики из README устанавливают оригинальный проект. Эта сборка
разворачивается из этого репозитория. Встроенный обновлятор отклоняет копии без
манифеста установки (`.lf-files.json`); такие копии обновляются вручную.
